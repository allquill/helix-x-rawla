# Rajputana Rawla portal

The member portal of the Rajputana Rawla of America: joining, your profile and
household, the member directory, events and volunteering.

This guide has two parts.

## [User Guide](/guide/joining.md)

For members. How to join, sign in, keep your profile and family up to date,
decide what others can see, register your household for an event, volunteer,
and download certificates.

Start with [Joining](/guide/joining.md), or go straight to
[Registering for an event](/guide/registering.md). Short answers are in
[Questions and answers](/guide/faq.md).

## [Setup and Administration](/setup/overview.md)

For the people who run the portal. Installing it, setting up the database,
configuring and deploying it — and the day-to-day work of an officer: reviewing
applications, managing members and chapters, running an event from creation to
close.

Start with the [Overview](/setup/overview.md). If something is not working, see
[Troubleshooting](/setup/troubleshooting.md).
